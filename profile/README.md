# QRtracer

**Create QR codes. Track scans. Update your links.**

[QRtracer](https://qrtracer.io/?utm_source=github&utm_medium=referral&utm_campaign=organisation) helps businesses create QR codes for menus, forms, events and printed materials. Download a static PNG without an account, or create a dynamic code to track scans and change its destination after printing.

New accounts get 30 days of unlimited dynamic-code creation, Analytics and QR Studio. After the trial, those features require a paid plan; existing redirects and scan collection continue. See [current plans and pricing](https://qrtracer.io/pricing).

## For developers

Connect QR generation to your application using the [API documentation](https://qrtracer.io/docs#api) and [OpenAPI specification](https://qrtracer.io/openapi.json).

The MCP endpoint is `https://qrtracer.io/mcp`. Read the [MCP setup instructions](https://qrtracer.io/docs#mcp) for authentication, available tools and ownership handoff. Client compatibility and account permissions apply.
